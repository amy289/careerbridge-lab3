# CareerBridge — Lab 3: HTML Forms + CSS Fundamentals

A complete beginner-friendly front-end project for the Web Technologies Lab 3 brief.

## Included pages
- `index.html` — portal landing page and featured jobs
- `login.html` — login form
- `register.html` — candidate registration form
- `employer.html` — employer/company registration form
- `jobs.html` — sample job listings with keyword/category/work-type filters
- `apply.html` — job application form with resume upload control
- `css/style.css` — shared styling, form states, layout and responsive breakpoints
- `js/app.js` — demo form feedback, simple validation helpers, job filtering and footer year

## Run the project
1. Extract the ZIP file.
2. Open the `Lab3_Job_Recruitment_Portal` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Navigate using the menu.

This is a static front-end demonstration. No PHP, database, email service, authentication server or file-upload server is included. The forms validate in the browser and show demo feedback only. The sample jobs and companies are fictional.

## Lab 3 learning checklist
- [ ] Every form control has a matching visible `<label>`.
- [ ] Required fields use `required`.
- [ ] Email fields use `type="email"`.
- [ ] Password fields use `minlength`.
- [ ] Phone field uses a pattern.
- [ ] Resume upload accepts common document formats and checks a 5 MB limit in the demo script.
- [ ] CSS uses variables, reusable classes, hover and focus states.
- [ ] Desktop forms use two columns and small screens use one column.
- [ ] Test invalid and valid form submissions.
- [ ] Test layout at 100%, 125% and 150% browser zoom.
- [ ] Capture at least 3 screenshots and write the lab report.
